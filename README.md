🎮 Sobre el juego

Pong Épico es una versión del clásico videojuego Pong, desarrollada con HTML5 Canvas y JavaScript.

Una combinación de nostalgia, diversión y una presentación visual moderna.

✨ Características

- 🏓 Jugabilidad inspirada en el Pong clásico.
- 🎨 Diseño visual personalizado.
- ⚡ Animaciones con HTML5 Canvas.
- 📱 Compatible con dispositivos móviles y computadoras.
- 🌐 Juego directamente desde el navegador.
- 📦 Disponible como APK para Android.
- 🔧 Sin dependencias externas.

🚀 Cómo jugar

1. Presiona el botón JUGAR PONG ÉPICO.
2. Espera a que cargue el juego.
3. ¡A jugar!

🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Canvas API
